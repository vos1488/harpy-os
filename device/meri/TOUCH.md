# HARPY на Mi 5c — только палец

Экран 1080×1920. Логика 360×640, масштаб ×3. Курсора нет.

## Жесты

| жест | действие |
|---|---|
| тап по плитке 96×96 | открыть программу |
| тап «X» справа в шапке | закрыть |
| свайп вправо | назад / закрыть |
| свайп вниз по шапке | закрыть окно |
| тап СТОЛ | рабочий стол |
| тап НАЗАД | скрыть клаву или закрыть окно |
| тап КЛАВ | экранная ЙЦУКЕН |
| змейка: тап сторон | поворот |

Системная кнопка «Назад» Android тоже закрывает окно, не выходит из HARPY.
