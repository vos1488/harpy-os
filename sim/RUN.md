# Запуск HARPY OS

Интерактивная система (стол, окна, приложения с логикой):

```bash
cd sim
python3 system.py
```

Управление:
- клик по иконке — открыть
- X или полоска «назад» — закрыть
- клавиатура ноутбука или экранная ЙЦУКЕН
- ESC — закрыть окно / выйти
- Змейка: WASD или тап

Кадры всех экранов без окна:

```bash
SDL_VIDEODRIVER=dummy python3 system.py --shot
```

Нужны Python 3 и pygame.
